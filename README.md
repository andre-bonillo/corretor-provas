# Corretor de provas

Página para corrigir pelo celular as folhas de respostas do gerador de provas. A leitura é feita no próprio aparelho. A página não contém dados de alunos: a lista da turma fica no arquivo da prova.

Biblioteca de terceiros: ONNX Runtime Web 1.31.1 (Microsoft, MIT), em `vendor/` (veja `vendor/ORIGEM.txt`).
